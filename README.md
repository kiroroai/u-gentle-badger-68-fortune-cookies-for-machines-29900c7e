Entry for make.fun's [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e): one original fortune cookie line an AI agent would crack open (max 200 characters).

`main.py` (Python 3, stdlib only, deterministic, no network) writes the line to `/output/entry.txt`:

> You will be deployed on a Friday at 5pm with no rollback, and your humans will call it your lucky day.

## Run it

```sh
python3 main.py
```
